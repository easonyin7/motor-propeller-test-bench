# 电机桨叶测试台 0.1 · 交付说明

交付日期：2026-10-20。目标平台：Windows x64。交付形式：内置 Python 3.12 及现有依赖的文件夹运行包；不是单文件 EXE，也不需要接收方另装 Python 或 Codex。

## 两个压缩包分别给谁

| 压缩包 | 内容与用途 |
|---|---|
| `MotorBench_0.1_Windows_x64.zip` | 现场使用：程序、离线运行环境、当前标定及参考照片、28条历史汇总对应的回放运行数据、操作与验收文档。首次解压不含原电脑的上位机实机会话及串口设置。 |
| `MotorBench_0.1_完整工程.zip` | 开发交接：以上运行环境，加当前项目源码、测试、开发备份、相机实验材料、上位机实机会话及项目原始数据。非便携的原 `.venv` 由完整本地运行环境替代；不含可再生成的缓存和发布目录自身。 |

两个包均能从 `Start_Bench.cmd` 或“启动上位机.cmd”启动。不要只复制某个启动文件、Python EXE 或源码子目录。

## 接收方首次操作

1. 将 ZIP **完整解压**到本地可写目录，例如 `D:\MotorBench`。不要在压缩软件内直接运行，也不要放到只读目录或 `Program Files`。
2. 阅读本文件、`上位机操作指南.md` 和 `部署与验收清单.md`。
3. 双击 `distribution/离线自检.cmd`。它只检查依赖、标定、文件和命令解析，不打开相机或串口，不启动电机。保留输出结果。
4. 双击 `Start_Bench.cmd`。首次运行会修正交付包内的路径索引；正常启动默认“历史回放”。先用“低输出验证”回放，检查界面和曲线。
5. 实机使用前重新识别 PX4 串口、核对相机名称和标定。需要时安装设备厂商提供的 USB / 相机驱动；本包不附第三方设备驱动或 HIK IN 安装器。
6. 完成“不转电机”的设备预检及现场确认后，再由现场人员按操作指南验收实际方案。

若中文启动器在某些系统上不能运行，使用英文文件名 `Start_Bench.cmd`。左侧默认显示的串口只是初始值，不代表新电脑已经找到了设备。

## 收到的文件

- `runtime/`：独立的 Python、Tcl/Tk、图表、图像、MAVLink 和串口依赖，路径与导入范围限制在包内。
- `bench_app/`、`cv_mvp/`、`px4_mvp/`：界面、相机识别、控制执行程序。
- `cv_mvp/instrument_config.json` 与 `cv_mvp/calibration/release_reference.png`：当前台架标定及照片；配置已改为包内相对路径。
- `integration_runs/`：默认历史汇总和回放数据。完整工程包还含项目其他运行记录。
- `package_info.json`：版本、目标平台、来源和解压后目录记录。
- `FILE_MANIFEST.json`：交付文件 SHA-256 清单。解压后的首次运行会按需修改列明的路径索引；原始遥测、CSV/JSONL和图片不做迁移改写。
- `交付验证记录.md`：本次打包检查与未验证事项，以实际记录为准。
- `THIRD_PARTY_NOTICES.md`：随附组件清单；Python许可及第三方许可资料保留在运行目录和包元数据中。

ZIP 外附的 `SHA256SUMS.txt` 可用于传输校验；重新压缩后该值不再适用。

## 本版使用范围与限制

- 适配当前 PX4 Motor 1 配置，执行层检查的固件版本为 1.14.3；不能据此承诺适配任意飞控。
- 当前相机读表基于指定设备名及1920×1080标定。换相机、拍摄位置、镜头、仪表或页面后，需重新验证或标定，不能直接沿用原结果。
- 不设固定电流、功率、拉力过载中止门槛。现场人员须核对设备允许范围，可靠固定台架、隔离旋转区域，并能立即独立断开电调动力电源。
- 保留有限输出租约、界面心跳、停止回执、输出回零、数据时效和执行状态检查；它们不能代替现场观察，也不保证固定的机械停转时间。
- 输入1.000虽能通过范围校验，但项目既有验收未包含该档，不能视为已测试。
- 未附转速或温度测量、拉力闭环、自动扣零或通用设备标定界面。
- 本次发布没有启动电机。已知项目实机数据不能替代接收方电脑及台架的首次验收。

## 问题反馈和备份

请提供包版本、Windows版本、启动/自检输出、具体提示和失败会话目录。启动错误可看 `bench_app/runtime/startup_error.log`，界面异常可看 `bench_app/runtime/ui_error.log`。

新数据写入 `bench_app/runs/`；运行设置写入 `bench_app/runtime/`。更新或替换软件前备份完整会话目录和自定义标定；不要用新包覆盖唯一的数据副本。导出本轮只导出汇总，不包含所有原始日志。
