# 电机桨叶测试台 · 上位机操作指南

适用版本：上位机 0.1，依据 2026-10-20 读取的当前代码编写。适用环境：当前 Windows 项目、PX4 Motor 1、USB 摄像头读取拉力表和电参数表。

本文面向现场操作人员。2026-10-20交付包内置 Python 环境，可解压后运行；开发目录仍可使用原环境。两者都需保留完整目录与标定文件，交付包首次使用另请阅读根目录的 `DELIVERY_README.md`。

## 1. 一次完整测试怎么做

**固定台架 → 接好设备 → 启动软件 → 选择实机测试 → 核对串口和标定 → 配置档位 → 设备预检 → 确认方案并运行 → 观察停转并确认 → 查看、导出数据。**

1. 在电调动力电源断开时，检查台架夹具、电机、桨叶及接线，清理旋转范围。台架应可靠固定，无需手扶。
2. 固定相机，让两块仪表清晰、完整地出现在画面中。关闭 HIK IN 等其他软件的相机预览，避免占用。
3. 接好飞控 USB、摄像头 USB 和测试所需供电；现场人员能立即独立切断电调动力电源。
4. 双击项目根目录的 **“启动上位机.cmd”**。启动后默认进入“历史回放”，不会自动启动设备。
5. 将“工作模式”改为 **“实机测试”**，点击串口旁的“刷新”，选择 PX4 对应串口；填写“电机 / 桨叶标识”。
6. 核对仪表标定，选择“主测 10–100% + 自动补8点”，确认自动补点选项已勾选。先核对10个主档位和自动补点规则，再点击 **“设备预检 · 不转电机”**。
7. 预检通过后，点击 **“开始实机测试”**。在确认窗口中检查档位、时间和三项现场条件，逐项勾选，再点击“确认并开始本轮实机测试”。
8. 运行中观察现场和“实时监控”。需要中止时点击 **“停止测试”** 或按 **Esc**；出现现场异常时立即独立断电。
9. 软件结束后，先观察桨叶确已完全停止，再点击 **“确认现场已停转”**，按实际情况完成确认。
10. 查看“测试曲线”和“历史记录”，点击“打开本轮记录”检查文件，或点击“导出本轮”保存汇总。

> **当前版本不设置固定的电流、功率或拉力过载中止门槛。** 读数变大不会单凭其大小触发软件停机。运行前须由操作人员核对设备允许范围和本轮方案，并保持现场看护及独立断电能力。软件的通信、画面时效、输出检查等功能不能替代这些措施。

## 2. 认识界面

| 位置 / 名称 | 用途与操作要点 |
|---|---|
| 工作模式 | “历史回放”读取已有日志；“实机测试”连接当前设备。启动时总是默认历史回放。 |
| 飞控串口 / 刷新 | 枚举串口后选择 PX4。历史值为 COM42，但重新插拔后可能改变；不要仅凭历史编号判断。 |
| 电机 / 桨叶标识 | 填写本轮实际测试对象，随会话保存。软件不会识别硬件型号，也不会据此设置设备极限。 |
| 仪表标定 / 更换标定配置 | 载入现有标定 JSON。此处没有鼠标选区、自动标定或曝光调节功能。 |
| 测试方案列表 | 显示输出指令、目标保持时间和档段。输入档位后点“加入”；选中已有行后点“移除”。 |
| 主测后自动补测300–500g（8点） | 主测预置默认勾选；完整主测后无需再次点击开始，自动计算并运行8个补点。只允许配合10%～100%的标准主测。 |
| 档间停机 / 秒 | 正常档间及统计不足重测前的等待时间，默认 5 秒，可设 5～120 秒。 |
| 忽略目标档前 / 秒 | 目标保持开始后，前多少秒不计入统计。默认 2 秒，可设 0～5 秒；不会缩短电机运行时间。 |
| 设备预检 · 不转电机 | 检查飞控、输出状态、相机及基线，不发送电机测试指令。 |
| 开始实机测试 | 弹出本轮方案和现场确认；确认后自动执行已列出的档位。 |
| 停止测试 / Esc | 请求当前任务停止，并阻止后续档位继续运行。 |
| 确认现场已停转 | 记录操作人员观察到的完全停转、夹具状态和有无异常。 |
| 从失败档继续 | 在满足条件时恢复未完成的原方案，保留已完成点。 |

左侧设置区域可用滚动条向下查看，底部开始、预检和停止按钮固定显示。运行中多数设置会锁定，不能临时修改本轮方案。

右侧三个页面的用途：

- **实时监控**：查看相机画面、拉力 / 电流 / 输入功率随时间的变化，以及可读率、拒读原因和画面时效。
- **测试曲线**：查看拉力–功率图，以及输出指令对应的拉力、电流、功率和拉力效率曲线。
- **历史记录**：查看历史汇总、以往保存的实机点、本轮点及回放点；注意“数据来源”列。

## 3. 配置测试方案

### 3.1 指令怎么填写

输入的是 0～1 范围内的归一化输出指令。例如：**0.100 表示 10%，0.500 表示 50%**，不要输入 10 或 50。

当前界面接受 **0.010～1.000，最多三位小数**，例如 0.073、0.428。方案按指令从小到大执行，重复档位不会重复加入，最多 64 个档位。

这些百分数是输出指令，不表示推力百分比、功率百分比或额定转速百分比。

### 3.2 预置方案

| 方案 | 档位 |
|---|---|
| 主测 10–100% + 自动补8点 | 0.100、0.200、0.300、0.400、0.500、0.600、0.700、0.800、0.900、1.000，然后自动补8点 |
| 低输出验证 | 0.025、0.030、0.040、0.050、0.060 |
| 中段曲线 | 0.065、0.100、0.150、0.220、0.330、0.400、0.500、0.600 |
| 高段曲线 | 0.700、0.750、0.800、0.850、0.900 |
| 全部已测档位 | 项目内置的 27 个历史档位，范围为 0.025～0.900 |

选择预置方案会替换当前列表，并取消“首档接续前一轮”勾选。主测预置会勾选自动补点，其他预置不会。手动加入或移除档位时取消自动补点；如果只想测10个主档位，可以主动取消自动补点勾选。

**“已测”表示项目曾测过这些指令，不表示换用其他电机、桨叶或供电后仍适用。** 当前主方案已包含1.000（100%），但此前尚未完成该档实机验收，开始前须核对当前设备允许范围，不能把软件支持视为硬件已验证。

### 3.3 每档运行多长时间

所有档位的目标保持时间均为 **10 秒**，界面暂不提供修改保持时间的入口。

| 指令范围 | 目标保持前的缓升 | 目标保持 |
|---|---|---|
| 0.010～0.025 | 无额外缓升 | 10 秒 |
| 0.026～0.060 | 通常 5 秒；0.030 / 0.035 / 0.045 为 4 秒，0.040 为 4.5 秒 | 10 秒 |
| 0.061～0.600 | 5 秒 | 10 秒 |
| 0.601～1.000 | 10 秒 | 10 秒 |

确认弹窗会列出每档“缓升+保持”时间。单档这两部分合计不超过 20 秒，但连接设备、检查基线、停机检查、保存和档间等待会额外耗时，不能直接用“档数×10秒”估算整轮时长。

## 4. 设备连接与相机标定

### 4.1 连接与启动

当前软件针对已验证的 PX4 Motor 1 配置工作，不是任意飞控配置的通用控制器。固件或输出映射改变时，预检可能拒绝继续，应核对配置；不要靠反复启动绕过。

启动器优先使用交付包内的 `runtime/`，开发目录则回退到 `cv_mvp/.venv`。搬移项目时应保留完整目录，不能只复制启动器或 `bench_app` 文件夹；交付包建议先运行 `distribution/离线自检.cmd`。

### 4.2 相机与标定

默认标定入口为 `cv_mvp/instrument_config.json`，使用 1920×1080 画面，识别上方拉力表（g）及下方电参数表。更换标定时，配置必须有对应参考照片及 g、V、A、W 字段。

操作要点：

1. 相机、台架和仪表保持固定，两块屏幕均清晰、无遮挡。
2. 在 HIK IN 等工具调整曝光或焦距后，先关闭其预览，再让上位机使用相机。
3. 明显移动机位、更换镜头或仪表、改变布局后，重新标定和验证，再载入配置。
4. 不把历史焦距、曝光参数当作所有安装位置的通用值；当前上位机没有直接调节这些参数的按钮。

每次实机会话都会复制本轮标定及参考照片。**正常退出仅记住串口和测试对象标识**；重启后模式、方案和相机配置路径等会恢复程序默认值，使用自定义配置时应重新核对。

## 5. 设备预检与正式运行

### 5.1 先做不转电机的预检

选择“实机测试”并设置好方案后，点击“设备预检 · 不转电机”。方案至少应保留一个档位；预检使用方案第一档对应的设置检查。

预检会检查飞控连接、固件与 Motor 1 配置、未解锁状态、输出回零、相机画面、字段单位、读数时效和停止状态基线。通过后还会继续监测 5 秒，最后显示“预检通过 · 电机未启动”。连接和基线确认会额外花时间。

拉力在 0000 / 0001 间小幅跳动并不必然失败。当前基线采用多次读数确认，短暂缺笔画帧可以跳过；普通首档要求拉力近零，通常绝对值不超过 2 g，首档属于高段极值流程时为 5 g。预检不会因勾选“首档接续前一轮”就放开此要求。

**电压应显示实际供电电压，不应人为要求显示 0 V。** 应核对无负载时电流、功率和仪表页面是否合理。执行层在档位启动前还检查静止电流基线不超过 0.02 A；飞控输出回零与仪表电压为零是两回事。

预检通过不会自动启动电机，也不会替代正式测试开始时的设备检查。

### 5.2 正式启动

点击“开始实机测试”，核对弹窗中的串口、Motor 1、各档指令、缓升/保持时间、档间停机和统计忽略时间。

只有现场实际满足以下三项，才勾选确认：

- 台架与桨叶固定牢靠，旋转区域已隔离，无需手扶。
- 现场有人看护，可立即独立切断电调动力电源。
- 已核对设备与档位，并知晓本轮不设固定过载中止门槛。

点击“确认并开始本轮实机测试”后，软件按冻结方案自动逐档执行。现场人员应持续观察，不能因自动运行就离开。

### 5.3 运行、重测与停机

每档按“基线检查 → 缓升（如有）→ 目标保持 → 停止与输出检查 → 统计保存”运行，正常档间按设定时间等待。

- 某档仅因关键量有效样本少于 10 个而不足：停机并确认输出后，等待档间时长，**自动重测同一档一次**。
- 重测成功：继续原方案下一档；仍不足：暂停方案，保留记录及不足标记。
- 通信、相机不可读、停止回执、输出或界面心跳等执行故障：中止后续档位，不自动重测。
- 可读率低于 70%但样本数量已够：记录统计提示，不单凭此触发重测。

自动重测不需要再次点击开始，因此看到某档重新运行时，先看状态说明；不要把首次停机当作整轮结束。

需要主动停止时点击“停止测试”或按 Esc。软件会请求停止当前档并阻止后续档位，需等待执行进程收尾。关闭窗口不能替代停机；运行时点击关闭，程序会先请求停止并提示等待。

结束或中止后，**看到“输出回零”仍须现场观察桨叶完全停转**。满足停转、夹具牢固、无明显异常后，点击“确认现场已停转”。待确认期间，程序会阻止开始新一轮或关闭窗口。

## 6. 残余拉力、补点与续测

### 6.1 停机后拉力不回零

当前规则区分首次独立测试与接续运行：

| 情况 | 拉力基线策略 |
|---|---|
| 未勾选接续的新会话首档、设备预检 | 要求近零基线 |
| 同一会话后续档位、自动重测 | 接受任意有效的残余拉力；窗口内变化也不以拉力不一致拒绝 |
| 从失败档继续 | 续测首档也按残余拉力策略处理 |
| 勾选“首档接续前一轮”的新方案 | 首档也允许任意有效残余拉力 |

“忽略残余拉力”只放开停止阶段的拉力基线条件，**不会扣零、校正或从目标测量结果中减去残余值**。该选项也不证明台架已停止或传感器正常；现场仍需核对实际状态。

独立的新测试不要仅为通过预检而勾选接续。若要重新清零或处理机械问题，先断开电调动力电源。

### 6.2 在 300～500 g 区间补 8 个点

标准主方案无需手动操作这一步：10个主测点全部有效完成后，软件按同一轮数据自动生成8个补点，停机等待后执行；直到18个点完成或中止后再做现场停转确认。覆盖不足、非单调或指令分辨率不足时停止并保留10个主测点；不要通过扩大输出绕过。

精确补点方案在生成后保存，界面会显示指令列表；它只使用本轮主测，不会读取另一台电机的历史数据。CSV和报告区分“主测”与“自动补点”，相同指令也保留两次测量。补点阶段故障后的续测使用保存方案，不重新插值。

如需另外手动补点，仍可使用以下独立流程：

1. 完成有足够覆盖范围的测量，确认现场停转。
2. 点击 **“按300–500g补8点”**。
3. 核对弹窗的数据来源：优先使用当前实机会话中的点，否则读取最近一次含数据点的实机会话。确认其电机、桨叶、供电和安装条件适用于本次补测。
4. 软件要求已有拉力随指令严格递增，且覆盖 300～500 g；条件不足时不会生成方案。
5. 核对插值得到的 8 个指令，确认替换当前方案。原有已保存数据不会删除，电机不会自动启动。
6. 程序会自动勾选“首档接续前一轮（忽略残余拉力）”。按现场状态核对后，点击“开始实机测试”，重新完成三项确认。

补点目标均匀分布于 300～500 g **内部**，不含两端；油门由已有点线性插值、取三位小数。**这只是生成待测试的输出档位，并非自动调节到指定拉力的闭环控制**，实测值可能偏离目标。

### 6.3 从失败档继续

1. 排查中止原因，确认现场已完全停转，并在软件中完成“确认现场已停转”。
2. 点击 **“从失败档继续”**，核对将执行的失败档及后续档位。
3. 重新完成现场确认，点击“确认并继续续测”。

续测保留已完成点和全部原始目录，沿用原方案的档间等待及统计设置。失败尝试、重测和续测目录分开保留；统计不足的旧点可从本轮曲线中移出，但原始记录仍保留。

重启后，软件只自动寻找**最近一次实机测试会话**是否可续测：它必须尚未完成且已记录现场停转确认。没有任意选择旧会话续测的入口；预检和历史回放不属于续测对象。

**续测沿用原会话的标定快照。** 相机位置、仪表、镜头、曝光或测试对象已改变时，取消续测，重新准备并开始新会话。

## 7. 读懂数值与曲线

| 显示项 | 含义 |
|---|---|
| 拉力 g | 上方数码管的有效识别读数；不自动扣除零偏。 |
| 电压 V / 电流 A | 电参数表的有效识别读数。 |
| 输入功率 · 计算值 W | 同一采样帧电压×电流；原始仪表功率仍保留在日志中。 |
| 拉力效率 g/W | 有效拉力与功率配对样本的拉力均值÷功率均值；不是百分比效率。 |
| “—”或曲线缺口 | 当前字段无效、画面过期或暂未采集，不表示读数为零。 |
| 整轮拉力可读率 | 识别结果中可读样本所占比例，不是人工核对后的正确率。 |

默认保持 10 秒、忽略前 2 秒，因此正常新点统计目标档的后 8 秒；缓升段不计入目标窗口。各字段按自身有效样本计算，数量可能不同。

拉力表存在频闪时，程序会扫描新取得的 LED 画面；当前发布帧缺笔画时，最多使用 0.25 秒内真实完整帧的拉力值，不拼接笔画或猜数字。因此拉力与同次发布的电参数可能存在这段时间差，不应把发布样本理解为全部传感量严格同时更新。

“测试曲线”包含五张图：拉力–功率、指令–拉力、指令–电流、指令–功率、指令–拉力效率。可取消 **“显示历史参考（统计口径存在差异）”**，只看本轮。灰色历史参考及历史复测点与新测可能有统计窗口、功率来源或测试对象差异，不宜直接混成一条同条件曲线。

## 8. 保存、导出与历史回放

### 8.1 自动保存与导出

每轮预检、实机测试或回放会自动保存到项目内 `bench_app/runs/日期时间_编号/`。点击“打开本轮记录”可打开对应目录；尚无本轮记录时，该按钮打开既有历史汇总目录。

| 文件 / 目录 | 用途 |
|---|---|
| `session.json` | 本轮模式、测试对象、冻结方案、统计、现场确认、重测及续测索引。 |
| `results.csv` | 本轮点的拉力、电压、电流、功率、效率和样本数量汇总。 |
| `report.md` | 可阅读的测试报告及异常、重测、续测说明。 |
| `curves.png` | 本轮界面保存的曲线图；无数据点的预检不保证有此图。 |
| `camera_config.json`、参考照片 | 本轮实机使用的标定快照。 |
| `stage_*` | 每档控制事件、识别结果、预览、停止检查及错误记录。 |

本轮结束后点击 **“导出本轮”**，选择一个文件夹。软件会在其中创建会话编号子目录，保存汇总 CSV、报告、会话 JSON 和当前曲线图；同名导出会再分子目录，避免覆盖。导出的曲线是否包含历史参考，取决于当前勾选状态。

**导出不是完整原始日志打包。** 需要交接或备份完整证据时，复制整个原始会话目录，并保留相关标定和引用文件。只复制 CSV 无法复核画面、停机或故障过程。

### 8.2 历史记录与回放

- 在“历史记录”中选中一行，可查看统计范围和原始目录；点击“打开选中原始记录”查看详情。
- “刷新记录”重新读取默认历史汇总及已保存会话。
- **“载入汇总CSV”只适配项目旧历史汇总格式**，不是通用 CSV 浏览器。它与本轮 `results.csv` 的列名不同，不要直接把本轮导出表作为该入口的输入；本轮点本来就可在历史记录中显示。
- 历史回放使用内置历史测量日志，不连接飞控或摄像头，不产生新的实测数据，按加速节奏播放。
- 回放建议选择“低输出验证”等有历史数据的预置方案。自动主测与补点仅用于实机，历史回放不支持该流程，也不会伪造100%档数据。历史记录中存在新会话点，不表示回放功能已支持播放所有新会话。

## 9. 常见问题处理

| 现象 | 处理方式 |
|---|---|
| 启动器提示找不到环境 | 保持完整项目目录，检查原 Python 环境是否仍在。不要只复制启动器。 |
| 串口刷新后没有 PX4，或连接失败 | 保持电机停止，核对飞控 USB 和供电、数据线及串口占用。重新连接后再次刷新；不要假设一定为 COM42。 |
| 相机无法打开 | 结束当前任务，关闭 HIK IN、Windows 相机及其他预览。核对 USB 连接，释放占用后重新预检。 |
| 相机画面全黑 | 保持电机停止，检查镜头、光照、USB 和取流；异常持续时结束任务后重新连接相机，再做预检。 |
| 拉力频繁显示“—”，预检失败 | 对照真实显示，查看拉力可读率和拒读原因；检查对焦、曝光、频闪、遮挡和机位是否仍符合标定。不要把漏读当作零值。 |
| 液晶电压、电流、功率全都不可读 | 检查 LCD 清晰度、反光、页面和小数点布局，以及位置是否偏出标定。换表或量程布局变化可能需要重标定。 |
| 基线不在近零范围 | 确认已无外载、电机停止，检查电流和拉力零位。需要机械调整或清零时先断开动力电源；新测试不要用接续选项掩盖未知负载。 |
| 提示没有电流 / 功率负载响应 | 保持停止，检查电调动力电源、电机和接线；该故障不会自动重测。 |
| 某档统计样本不足 | 软件会在正常停机后仅自动重测一次；仍不足时，先改善图像并确认现场停转，再从失败档继续。 |
| “从失败档继续”不可用 | 检查是否已结束任务并确认现场停转，最近实机会话是否确有未完成档位；已完成会话不能续测。 |
| 补点提示覆盖不足或不单调 | 核对数据来源和测试对象，先补足可用主测数据或排查异常点；不要修改结果强行生成。 |
| 停止后暂时不能关闭或重新开始 | 等待控制进程收尾，并完成“确认现场已停转”。软件回零不等同于机械停转。 |
| 画面、通信或界面心跳异常导致中止 | 先确认现场停转、排查连接或软件状态，再决定续测；不要反复点击开始。 |
| 记录保存失败 | 先确认停转，检查磁盘空间、目录权限和文件占用。保留该轮原始目录，不将保存失败当作完成。 |

排查时先提供**完整会话目录**、出现问题的档位、界面提示和当时仪表实际读数。软件主界面异常另可查看 `bench_app/runtime/ui_error.log`；仅有错误截图通常不足以复核采集和停机过程。

## 10. 收尾及当前功能边界

1. 本轮结束后完成现场停转确认。
2. 检查报告中的完成状态、有效样本数量及统计提示，保存或导出数据。
3. 切断电调动力电源，再进行拆桨、接线、夹具或传感器调整。
4. 正常关闭软件；备份需要保留的完整会话目录。

本版不提供转速或温度测量、拉力闭环、自动扣零、机型极限自动识别、通用相机参数控制或独立安装包。输出租约、心跳超时和停止回执用于执行检查，不能推导或承诺桨叶的实际停转时间。
