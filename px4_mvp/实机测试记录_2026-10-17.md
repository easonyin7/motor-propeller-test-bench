# PX4 MVP 首次电机启停测试

日期：2026-10-17。

结论：**单电机低输出、1 秒运行和停止的基础实机测试通过。**

## 现场条件

操作者在本次测试前确认：桨叶已全部拆除、电机可靠固定、电调已供电且能独立断电、信号线接 MOTOR1。

## 测试前读取

- 端口：COM42；PX4 1.14.3；system/component 为 1/1。
- 飞控未解锁；COM_MOT_TEST_EN=1。
- PWM_MAIN_FUNC1=101，对应逻辑 Motor 1。
- PWM_MAIN_TIM0=-4，与上次 DShot300 配置一致。
- 无飞控参数写入、固件更新或解锁操作。

配置证据：`logs/20261017_155911_565700.json` 和同名 CSV。

## 执行与证据

对逻辑 Motor 1 发送一次 MAV_CMD_ACTUATOR_TEST，归一化输出 0.02，有效期 1 秒。该数值不是实际转速、推力或额定功率百分比。

| 事件 | 日志 monotonic_s | 结果 |
|---|---:|---|
| 发送运行指令 | 994.437 | value=0.02、timeout=1、Motor 1 |
| 收到运行 ACK | 994.453 | ACCEPTED |
| 运行期间输出回报 | 994.515～995.421 | port 0 第 1 路为 146，第 2 路为 0 |
| 发送 NaN 停止请求 | 995.453 | 请求停机输出 |
| 收到停止 ACK | 995.468 | ACCEPTED |
| 观察到输出恢复 | 995.531 起 | 第 1 路为 0 |
| 发送释放测试控制请求 | 995.640 | timeout=0 |
| 收到释放 ACK | 995.656 | ACCEPTED |

测试前后均收到第 1 路为 0 的输出回报。原始数值 146 不能解释为 PWM 微秒。采样与 USB 传输存在延迟，表中时间不用于认定物理引脚或实际电机的响应时间。

原始证据：`logs/20261017_155933_174700.csv`。

操作者现场反馈：**“电机短暂转动，随后完全停止”。**

因此，本次同时取得飞控命令回执、飞控输出回报以及操作者对实际电机启停的观察。

## 已验证范围与后续工作

已验证 PC → USB MAVLink → PX4 → ESC → 单电机的基础启停链路；无桨、单一低输出、单次 1 秒。

尚未验证多档输出响应、重复性、实际 RPM、Ctrl+C/强制终止/拔 USB 后的实际停机、带桨负载或 CV 采集。后续继续先做无桨验证，再集成自动分档和摄像头读表。
